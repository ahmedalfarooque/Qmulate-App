# Regulatory reference library

Structured summaries of the Saudi Awqaf regulatory sources that govern QMULATE's work as
professional Nazir. These were ingested from the SharePoint engagement folder
(`.../Engagements/Qmulate/References & Regulations/`) and the Company Details folder.

> [!important] These are faithful **structured summaries**, not verbatim copies.
> The authoritative full texts are the originals in SharePoint and the versions published on the
> General Authority for Awqaf website (`www.awqaf.gov.sa`). Arabic is the controlling language of
> Saudi law; where an English translation is summarized, the Arabic prevails. Confirm the current
> version and any amendments with Saudi counsel before relying on any point for execution.

## Translation note

The official English translation renders **النظارة / الناظر** as "Beholding / Beholder." Throughout QMULATE
docs we use the conventional **Nazarah / Nazir** (trusteeship / trustee). They are the same terms.
